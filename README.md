## 📝 Descrição do Projeto

Este repositório reúne quatro scripts desenvolvidos em Python para automatizar processos de tomada de decisão e análise de dados em diferentes áreas, incluindo gestão financeira, monitoramento climático e administração acadêmica.

Os algoritmos utilizam estruturas condicionais, laços de repetição e operações matemáticas para processar informações fornecidas pelo usuário, aplicar regras de negócio e apresentar resultados de maneira dinâmica.

## ⚙️ Módulos do Sistema

### 📊 1. Processamento de Vendas — `main1.py`

Sistema para simulação de compras e fechamento de carrinhos de venda.

- 🛒 Calcula o subtotal dos produtos.
- 💰 Aplica descontos progressivos de acordo com o valor da compra, chegando a até 10%.
- 🛡️ Valida preços e quantidades para evitar valores negativos.
- 🧾 Apresenta o total calculado após os descontos.

### 🌡️ 2. Analisador de Clima — `main2.py`

Script para análise de temperaturas registradas durante uma semana.

- 🌡️ Processa os valores de temperatura informados.
- 📈 Calcula a média das temperaturas.
- 🚨 Identifica condições extremas, abaixo de -5 °C ou acima de 45 °C.
- 📊 Apresenta os resultados da análise climática.

### 🎓 3. Gestão de Notas — `main3.py`

Sistema de avaliação acadêmica que processa notas e calcula o desempenho dos alunos.

- 📝 Recebe e processa as notas informadas.
- 🧮 Calcula médias ponderadas.
- ✅ Classifica os alunos como “Aprovado”, “Recuperação” ou “Reprovado”, conforme os critérios definidos no algoritmo.
- 📋 Exibe os resultados da avaliação.

### 💰 4. Simulador de Poupança — `main4.py`

Ferramenta para simulação de crescimento financeiro ao longo do tempo.

- 💵 Permite informar um valor inicial e aportes mensais.
- 📈 Calcula o crescimento do saldo com juros compostos.
- 🎯 Acompanha a evolução do investimento em direção a uma meta financeira.
- 📊 Apresenta uma projeção do saldo acumulado.

- 🐍 **Linguagem:** Python 3.10 ou superior.
- 💻 **Ambientes de desenvolvimento:** Google Colab, Jupyter Notebook ou terminal.
- 🧠 **Paradigma:** programação estruturada e imperativa.
- 📚 **Bibliotecas:** biblioteca padrão do Python, sem necessidade de dependências externas.

## 📊 Regras de Negócio e Aprendizados

O desenvolvimento dos quatro módulos permite aplicar conceitos fundamentais da programação:

- 🛡️ **Validação de Dados:** verificação de preços, quantidades e valores informados pelo usuário.
- 🔢 **Acumuladores e Contadores:** utilização de variáveis para somar valores e calcular médias.
- 🔀 **Fluxo de Controle:** aplicação de estruturas `if`, `elif` e `else` para definir diferentes resultados.
- 🔁 **Estruturas de Repetição:** processamento de conjuntos de dados e cálculos realizados em sequência.
- 💹 **Cálculos Financeiros:** aplicação de descontos, juros compostos e projeções de saldo.
- 📊 **Análise de Dados:** interpretação de temperaturas e resultados acadêmicos.

## 🔧 Como Executar

### 📋 Pré-requisitos

- Python 3.10 ou superior instalado.
- Terminal, Visual Studio Code, Google Colab ou Jupyter Notebook.

### ▶️ Passo a Passo

**1. Clone o repositório**

```bash
git clone https://github.com/SEU-USUARIO/python-utility-scripts.git
```

**2. Acesse a pasta do projeto**

```bash
cd python-utility-scripts
```

**3. Execute o script desejado**

Para processamento de vendas:

```bash
python main1.py
```

Para análise de clima:

```bash
python main2.py
```

Para gestão de notas:

```bash
python main3.py
```

Para simulação de poupança:

```bash
python main4.py
```

> 💡 Execute cada arquivo separadamente, conforme o módulo que deseja utilizar.
